## 🚀 **Key Projects**
Here are some projects I’m especially proud of:

### 🌟 [Autonomous Wheelchair](https://github.com/YoussefAdel170/Autonomous-Wheelchair)
- **Tech**: ROS, Gmapping, SLAM, Navigation, ROSBridge (WebSocket), React, HTML, CSS, Bootstrap  
- **Description**: A real & simulated autonomous wheelchair capable of mapping, navigation, and obstacle avoidance, with web-based control and monitoring.

### 🌟 [School Management System](https://github.com/YoussefAdel170/School-Management-System/)
- **Tech**: React, Redux, React Router, React-Bootstrap, PHP, MySQL  
- **Description**: A role-based system for Admins, Teachers, Students, and Parents with authentication, access control, and a responsive UI.

### 🌟 [Autonomous Mobile Robot](https://github.com/YoussefAdel170/Autonomous-Mobile-Robot)
- **Tech**: ROS, A*, DWA, LIDAR, Kinect Camera  
- **Description**: An autonomous robot with global & local path planning, navigation, and dynamic obstacle avoidance.

### 🌟 [Door Locker Security System](https://github.com/YoussefAdel170/Door-Locker-Security-System)
- **Tech**: Embedded C, Proteus, Atmega32 (UART, GPIO, I2C, Timers), LCD, Keypad, DC Motor  
- **Description**: A secure door-locking system with password-based access control.

### 🌟 [MovieSphere](https://github.com/YoussefAdel170/moviesphere)
- **Tech**: React.js, JavaScript, HTML5, CSS3, React-Bootstrap  
- **Description**: A modern movie discovery web application built with React.
